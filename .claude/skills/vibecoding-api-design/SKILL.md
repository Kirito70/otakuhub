# VibeCoding API Design Skill

This skill contains the **OpenAPI contract templates**, request/response schemas, and any VibeCoding‑specific conventions (e.g., authentication via JWT, rate‑limiting rules, naming conventions for endpoints).  It is used by the `vibecoding-architect` and `vibecoding-api-designer` agents.

## Sections
1. **Project Overview** – short description of VibeCoding.
2. **Authentication** – JWT access/refresh token flow.
3. **Common Error Model** – `ErrorResponse` schema.
4. **Endpoint Template** – example for a CRUD resource (`/api/v1/projects`).
5. **Rate Limiting** – token‑bucket limits for public endpoints.
6. **Versioning** – use `/api/v1/` prefix.

> The actual OpenAPI YAML/JSON is generated by the agent at runtime; this markdown only provides the narrative and placeholders.
